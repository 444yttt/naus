# 部屋写真 × 家具3D 合成CG ハンドオフ・データセット

## 目的
実際の部屋写真(リビングダイニング中心)に、家具の3Dモデルを**写真と一致する遠近・カメラ姿勢**で、**間取り図と一致する位置関係**で配置し、接地影・反射を含めて自然に合成した「試作CG」を作ること。
このデータセットは Codex / Claude 等のAIコーディングエージェントに渡すための自己完結資料です(外部送信・ログイン不要の範囲で完結)。

## 成果物の定義(詳細は SPEC.md)
- リビング中心に計5視点(視点が被らない)の合成JPEG(写真のフル解像度)+各視点の検証画像。寝室は別枠。
- 全視点で**同一の家具レイアウト**(1つの平面座標系から各カメラに変換)。
- これは「試作CG」であり、納品実績・確定プランではない。ソファ等の配置は仮置きで、ユーザーと相談予定。

## ユーザーが前回不満だった点(原文どおり)
1. 「奥行きと平衡感覚がおかしい」
2. 「フローリングの目地線を直線ガイドに法線を厳密に導け」
3. 「間取り図を渡したのに位置関係を理解できていない」

→ 1は焦点距離・カメラ高さ・ロールの推定誤差、2は床法線(=垂直消失点と床目地の消失点から決まる床平面)を目地線から厳密に導いていないこと、3は家具位置を写真ごとに目分量で置き、間取り図の共通座標系に拘束していなかったことへの指摘です。

## 今回の最終出力で期待する水準
- **位置関係が間取り図と一致**:斜めFIX窓、バルコニー窓、グレー壁、キッチンアイランドに対する家具の位置・向きが全視点で矛盾しない。
- **遠近が写真と一致**:床目地線・垂直線・窓枠の延長線に家具の稜線が乗る(検証画像で目視確認できること、再投影誤差を数値で報告)。
- **接地と影が自然**:脚・台座が床に接地し、コンタクトシャドウ+窓光方向に合った影、床の映り込み。
- **質感はCGっぽさを抑える**:写真の露出・色温度・ノイズ・被写界深度に合わせ、白飛び/平坦なシェーディングを避ける。

## 注意
- 秘密情報・ログイン情報は含めていません。写真のEXIFにGPS情報はありません(確認済み)。窓外に都市景観が写っており、景観から立地が推測され得る点のみ留意。
- ログインが必要なモデル配布元を使う場合は、必ず事前にユーザー承認を得ること。
