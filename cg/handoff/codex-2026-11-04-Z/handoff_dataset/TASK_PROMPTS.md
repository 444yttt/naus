# TASK_PROMPTS(そのままコピペして渡す)

共通の前提: データセットのルート(README.md がある場所)をカレントディレクトリにして実行させる。ネットワーク利用・ログインはユーザー承認がある場合のみ。

---
## Codex 用

```
あなたはこのリポジトリ(カレント=データセットのルート)で作業する。README.md, SPEC.md, LAYOUT_FACTS.md, MODEL_SOURCES.md, images/INDEX.md を最初に全部読むこと。

目的: images/photos の実写真に家具3Dを合成した「試作CG」を作る。リビング中心に視点が被らない5枚(u1, u2, p09 + 2枚を p01/p02/p03/p13 等から選定)、全視点で同一レイアウト。寝室 p17 は別枠。

厳守:
- 位置は images/plan/floorplan_large.jpg と LAYOUT_FACTS.md の平面座標系(原点=鋭角コーナー、x=バルコニーガラス沿い、斜めFIX窓 70.7°、グレー壁 x=9.40)で1つの layout ファイルに定義し、全視点に同じ変換で投影する。写真ごとの目分量配置は禁止。
- ダイニングは240cm級、images/plan/redbox.jpg の赤枠(斜めFIX窓沿い、アイランド左下からバルコニー方向、窓壁とほぼ平行)。
- 家具は BoConcept 中心+ハイブランド、TV/スピーカーは B&O(models/ の公式OBJ、mm・Y-up)。自作ボックスは最終手段で、使ったら報告。ログインが必要な配布元は使わず、必要なら候補とURLを報告して止まる。

手順:
1. 各写真で LSD 等により線分抽出→床目地線群・垂直線群・第3方向群に分類→消失点を最小二乗(RANSAC)で推定。
2. 消失点から焦点距離 f(主点=画像中心)と回転 R を推定。床法線は垂直消失点と目地の消失点から厳密に導く(目地線を直線ガイドにする)。calib/ の前回値は初期値として比較のみ。
3. 床スケール: 床板幅 0.150m(仮定)を目地間隔から使いカメラ高さ h を出し、天井高 2.45m・窓/壁ラインで独立検証。LAYOUT_FACTS.md の h+h_ceil 矛盾を解消し、どちらの仮定が崩れたか報告。
4. 平面座標→各カメラの外部パラメータ(位置・ヨー)を、斜めFIX床ライン・バルコニー床ライン・グレー壁床ラインの再投影で最適化。
5. Blender(Cycles, CLI)でシーン構築: 床平面(shadow catcher+弱い反射)、窓方向の面光源+太陽、写真に合わせた露出・色温度。
6. 接地影(コンタクトシャドウ)と床反射をレンダリングし、写真に合成(フル解像度、ノイズ・ぼけ・トーンを合わせる)。
7. 検証画像: 目地線延長・垂直線・モデル拘束線・家具フットプリントと接地点を重ね、再投影誤差を文字で記入。

完了条件:
- out/ に 5視点+寝室の *_final.jpg(元写真と同画素数)と *_check.jpg。
- 全拘束線で再投影 rms ≤ 5px、|median| ≤ 3px(満たせない場合は理由)。
- 全視点で家具の平面座標が同一(layout ファイル1つ)。
- 前回の欠陥(天板明るすぎ、ソファ平坦、寝具白飛び、接地弱い、簡易形状)を各々どう解消したか。

報告項目: 各視点の f / h / R(pitch・roll・yaw)/ 再投影誤差表、使用モデルと入手元・ライセンス、自作形状の有無、未解決点、ユーザーに相談すべき配置案。これは試作CGであり納品物ではないと明記。
```

## Claude 用

```
カレントディレクトリは部屋写真×家具3D合成のハンドオフ・データセットです。まず README.md、SPEC.md、LAYOUT_FACTS.md、MODEL_SOURCES.md、images/INDEX.md を読み、images/plan/floorplan_large.jpg と images/plan/redbox.jpg、images/photos/u1.jpg・u2.jpg・p09.jpg を実際に画像として見てから計画を立ててください。

ユーザーの前回の不満(必ず解消):「奥行きと平衡感覚がおかしい」「フローリングの目地線を直線ガイドに法線を厳密に導け」「間取り図を渡したのに位置関係を理解できていない」。

やること:
(1) 消失点推定: 各写真で床目地線・垂直線・窓枠線を抽出し、消失点を頑健推定。
(2) 焦点距離と回転: 直交消失点から f と R を求め、目地線から床法線を厳密に決める。
(3) 床スケール: 床板幅0.150m仮定でカメラ高さを決め、天井高2.45mで検証(前回 h+h_ceil が 2.84〜2.93m と矛盾、原因を特定)。
(4) 共通レイアウト: LAYOUT_FACTS.md の平面座標系で家具を1ファイルに定義し、各写真の外部パラメータを壁・窓の床ラインの再投影で合わせる。ダイニング240cm級は赤枠位置、TV/スピーカーは B&O 公式OBJ(models/)、他は BoConcept 中心+ハイブランド。ログイン必須の配布元は使わず候補を報告。ソファ等は仮置き(後でユーザーと相談)なので、変更しやすく。
(5) Blender 等でシーン化し、接地影・床反射・窓光を作り、写真のトーンに合わせて合成。CGっぽさ(均一な明るさ、白飛び、平坦な布)を避ける。
(6) 検証画像: 目地線の延長・垂直線・家具の接地点とフットプリントを重ね、誤差数値を記入。

成果物: out/ にリビング5視点(視点が被らない)+寝室1視点の *_final.jpg(フル解像度)と *_check.jpg、layout ファイル、使用スクリプト。
完了条件: 再投影 rms ≤ 5px・|median| ≤ 3px、全視点同一レイアウト、間取り図との位置一致を平面図上の重ね描き(out/plan_overlay.png)で示す。
報告: 視点ごとの f/h/姿勢/誤差表、モデル出典とライセンス、自作形状の有無、前回欠陥の解消状況、未解決点。これは「試作CG」であり納品実績ではありません。
```
