# 受け入れ条件(すべて自動で検証し、結果を report.md に貼る)

## 1. 配置(テーブルをアイランドに詰める)
- [ ] テーブル短辺の端が、アイランド端面に接している(最近接距離 0〜数mm。数値を出す)。
- [ ] めり込みがない。椅子6脚が、壁・アイランド・窓ガラス・マリオンに干渉していない。
- [ ] `layout.json` の差分が、テーブル+椅子6脚のみ。 `diff` を貼る。
- [ ] `07_plan.png` を更新(詰めた状態。「約420mm」の赤線と注記は削除)。
- [ ] テーブルとアイランドの接合部に接触の影(AO)があり、光漏れがない(4枚目、2枚目、5枚目の見える視点で)。

## 2. Eames の影と光(2枚目を中心に、1・3・4枚目も)
- [ ] 2枚目: 椅子の足元の影の暗さが、同じ日陰領域の既存の影(窓枠の反射帯など)と同程度。 床の影領域の輝度を、W版・X版・写真の既存の影で比較して数値を出す。
- [ ] 背面が一様な暗い茶色にならない。窓外の明るさに対する回り込みの光が見える。 背面の輝度の最大/最小の比を、W版・X版で出す。
- [ ] 形状は W版の補修済みサーフェス(ジャギーなし)を維持。

## 3. ソファの陰影と質感(1枚目、3枚目)
- [ ] 面ごとの明暗に差がある。 ソファの各面の平均輝度の標準偏差を、W版・X版で出し、X版が大きいこと。
- [ ] 窓側の面は暖色寄り、日陰側は冷色寄り(色温度の差の数値)。
- [ ] 3枚目: 座面の上面に、窓外の緑の映り込み(色被り)が弱く見える。
- [ ] 縫い目の陰影と、革の微細な反射(シーン内のマテリアルの設定で行う。後処理のレタッチは不可)。

## 4. 合わせ込み(2枚目、5枚目)
- [ ] 建築側のRMS誤差(原寸px)を W版より下げる。 目標は 7px 以下。達成できなければ、値と理由を記録する。
- [ ] 床の接地線が、家具の脚元で浮いて見えない(`contact_coverage.json` と同形式で出力)。
- [ ] 他の3視点のカメラは W版と同一(差分0)。

## 5. 4枚目の床の青み
- [ ] CGが足した反射による青みの増加を抑える。 家具から離れた床領域(家具の影響を受けない部分)の平均色が、元写真と X版で一致する。(元写真は変えない)
- [ ] 家具の近くの反射は残す。 反射が消えていないこと。

## 共通(不変の確認)
- [ ] 元写真の未加工領域の誤差が、8bitで最大2以下。
- [ ] 粒状感: 各視点でσが W版と同じ設定(最小 0.65/255)。 周辺部のにじみのパスも同じ。
- [ ] 窓・外景の既存反射の遮蔽が、動いた家具に対して正しく更新されている。
