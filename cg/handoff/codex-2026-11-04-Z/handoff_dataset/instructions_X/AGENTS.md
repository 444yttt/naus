# AGENTS.md — 原宿3LDK 試作CG 納品版(X)

## 目的
`source/Harajuku_LDK_W.blend` と W版の出力を元に、**納品版(X)** を作る。
作業範囲は次の5つだけ(すべてユーザー承認済み。00_user_instructions.md)。
1. ダイニングテーブルを、アイランドに詰める(配置変更)。
2. 2枚目の Eames の影を弱め、背面に回り込む光を足す。
3. ソファ(1枚目、3枚目)の面ごとの陰影と革の質感を強める。
4. 2枚目と5枚目の建築の合わせ込みを再調整する。
5. 4枚目の床の青みのうち、CGが足した反射による分を抑える。
全体として、W版で達成した合成精度(床の反射・接地・遮蔽・粒状感)は下げない。

## 絶対に守る
- 背景写真は未加工。生成AIによる置換・補修をしない。画像のレタッチで直さず、3Dシーンとレンダー設定で直す。
- 5視点とも同じ共通配置にする。視点ごとに家具を動かさない。
- 部分レンダーの使い回しをしない。5視点すべてを再レンダリングする。
- 原寸、sRGB。JPG と PNG は同内容で出す。
- カメラを変えてよいのは、2枚目(u2)と5枚目(p13)の再合わせ込みだけ。他の3視点は W版と同一。
- 動かしてよい家具は、テーブル(Linha)と椅子6脚(Torii)だけ。他の家具は、位置・向きを W版と同一にする。材質の調整は、項目2と3の範囲だけ。
- 報告は、合成精度と変更内容だけ。権利・予算・サイト・配置の是非などの意見は書かない。
- 失敗した検証を「完了」と報告しない。失敗は失敗として、出力をそのまま書く。
- 元ファイルを上書きしない。出力は `out_X/` に新規で作る。

## 作業の流れ
1. 入力を取得し、`sha256sum` を記録する。
2. 変更前の状態(カメラ5つ、家具の位置と回転、ライト、材質)をJSONで書き出す。
3. GOAL_PROMPT.md の順(配置 → 材質 → カメラ → 床の色)で変更する。1つ終えるごとに、そのプレビューを保存する。
4. 5視点を W版と同じ設定で再レンダリングする。
5. ACCEPTANCE.md を全て実行して `report.md` に書く。

## 役割
- あなた(Codex)は実装担当。 Claude はレビュー担当で、出力を受け取って合成精度を評価する。
- レビューしやすいように、`REVIEW_HANDOFF.md` の通りに成果物を揃えて渡す。
- 自分の出力の良し悪しは、数値と事実だけで書く。「良くできた」といった評価はレビュー担当に任せる。
