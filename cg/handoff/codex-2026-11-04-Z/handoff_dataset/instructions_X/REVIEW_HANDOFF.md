# レビューへの受け渡し(Codex → Claude)

## 渡すもの
- `out_X/` 一式(01〜05 のJPG/PNG、00、06、07、08)
- `source/Harajuku_LDK_X.blend`
- `report.md`: 変更点(テーブルの移動量と回転角、椅子の補正量)、ACCEPTANCE の全項目の結果(数値)、不合格・未実施の項目、「未対応の観察」
- `revision_QA.json`、`details/contact_coverage.json`(W版と同形式)
- W版との差分: `layout.json` の diff、u1・p09・p01 のカメラの差分(0であること)、u2・p13 の再調整後の値(`camera_fit_X.json`)
- 配置前後の blend 内の数値: テーブルとアイランドの最近接距離(変更前、変更後)

## レビュー担当が見る観点(合成精度だけ)
- 床の反射、接地、接触の影(特にテーブルの脚と、テーブル端とアイランドの接合部)
- Eames の影と回り込み光、ソファの陰影と質感、u2・p13 の接地、4枚目の床の色
- 既存の窓・外景反射の遮蔽、粒状感、周辺部のにじみ
- W版と比べた、意図しない変化(カメラ、背景、他の家具)
- 5視点の一貫性

## 差し戻しの扱い
- レビューの指摘は、Claude から Codex へ、番号付きで渡される。指摘ごとに、対応内容と再検証結果を `report.md` に追記する。
- 指摘に同意できない場合は、数値と画像を根拠に、理由を書く。
