NAUS 千鳥ヶ淵リビング Blenderキット（Blender 4.2 LTS 用）

中身
  build_room.py … 実行すると部屋が組み上がるスクリプト
  trees.jpg     … 窓の外の景色（スクリプトと同じフォルダに置く）

使い方
  1. このフォルダを解凍して、好きな場所に置く（例：ドキュメント\naus_blender）
  2. Blender を起動 →「General」で新規ファイル
  3. 上のタブ「Scripting」→ テキストエディタの「開く」で build_room.py を選ぶ
  4. ▶（Run Script）を押す
  5. 同じフォルダに naus_living.blend が保存されます
  6. 上のタブ「Layout」に戻り、F12 でレンダリング（写真と同じ構図）

カメラ
  Cam_Photo   … 元の写真と同じ構図（縦長 1536×2048）
  Cam_Web16x9 … 横長のWeb用。使うときは
                 アウトライナーでカメラを右クリック →「アクティブカメラに設定」、
                 出力プロパティで解像度を 1920×1080 に変更

よく触るところ
  間接照明の明るさ … マテリアル「CoveLED」の Strength（初期値 45）
  窓からの光       … ライト「WindowDaylight」のパワー（初期値 900W）
  ダウンライト     … ライト「DownlightSpot0〜6」のパワー（初期値 18W）
  床の色           … マテリアル「WalnutFloor」のレンガテクスチャの色1/色2
  全体の明るさ     … レンダープロパティ → カラーマネジメント → 露出

寸法は写真からの推定です。違うところがあれば教えてください。
